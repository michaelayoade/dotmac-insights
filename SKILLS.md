# Skills Index

Quick reference for available Codex skills in this repo.

## Core Engineering
- `coding-standards`: Apply DotMac BOS Python standards.
- `qa`: Code review, edge cases, and risk assessment.
- `test`: Test generation, running, and coverage guidance.
- `performance-review`: Query performance and index checks.
- `db`: Models, migrations, and database operations.

## Delivery & Product
- `product-spec`: Requirements, scope, acceptance criteria.
- `architecture-design`: System design, tradeoffs, ADRs.
- `delivery-planning`: Milestones, dependencies, rollout.

## Security & Ops
- `security-review`: Auth, data handling, threat modeling.
- `observability`: Logging, metrics, tracing, runbooks.

## Frontend
- `frontend-design`: UI/UX layout, responsiveness, accessibility.

## Example Commands
```
/architecture-design plan "feature-name"
/product-spec draft "feature-name"
/delivery-planning plan "feature-name"
/security-review scan app/path/to/file.py
/observability plan "feature-name"
/qa review app/path/to/file.py
/performance-review query app/path/to/file.py
```
